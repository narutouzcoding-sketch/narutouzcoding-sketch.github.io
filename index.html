D Drive Cloud

Access your Google Drive from a familiar Windows folder.

What the application does

D Drive Cloud is a personal-use desktop configuration of rclone and WinFsp. It mounts a selected folder in the owner's Google Drive as a Windows filesystem location.

The owner can browse, read, create, update and delete files through the mounted folder. Google Drive stores the remote files. This informational website has no sign-in form and does not receive Google Drive files or authorization tokens.

Google account access

The desktop application uses Google's OAuth authorization flow. It requests Google Drive access so it can work with existing files as well as newly created files. The Google permission covers the authorized Drive account; the local mount is configured to use a selected folder.

All Drive access requires the account owner's consent. Publishing this website does not make the owner's Drive files public or change their sharing settings.

Storage and compatibility

The desktop mount is configured with --vfs-cache-mode off, which streams file contents without a persistent rclone file-content cache. RAM buffers are used during transfers. The software, OAuth configuration and small diagnostic logs still occupy local disk space. Other applications and the operating system may create their own files or caches.

An internet connection is required. Cache-free mode supports sequential writes; some applications require a local file cache and are not compatible. Interrupted uploads may have to be restarted.
