Privacy Policy

Effective date: 11 November 2026

D Drive Cloud is a personal desktop integration maintained by narutouzcoding-sketch. It uses rclone and WinFsp to connect the owner's Windows filesystem to Google Drive. This policy describes that integration and this informational website.

Data accessed and purpose

With the account owner's Google OAuth consent, the desktop integration accesses Drive file and folder names, identifiers, sizes, timestamps and file contents. This access is used only to provide the filesystem operations requested by the owner: listing, reading, creating, updating and deleting files.

The Google authorization scope permits access to existing Drive files, because the mount must work with files already in the account. The local configuration limits the mounted location to the owner's selected folder. It does not automatically alter existing Drive sharing permissions.

Where data is processed and stored

  • File transfers and Drive API requests go directly between the owner's computer and Google. There is no separate D Drive Cloud application server receiving Drive data.
  • Google Drive stores the remote files under the owner's existing Google account and sharing settings.
  • OAuth access and refresh credentials are stored locally in the owner's rclone configuration so the desktop integration can reconnect. They are not published in this website or its repository.
  • The configured cache-free mode does not maintain a persistent rclone cache of file contents. Transfers use RAM buffers. Small application configuration files and diagnostic logs remain on the computer; logs may contain file paths or error details.
  • The operating system or other applications may keep their own downloaded files, thumbnails or caches. Those are outside the rclone file-cache setting.

Sharing and limited use

Drive data is used only for the desktop filesystem features described above. It is not sold, used for advertising, or shared with an intermediary analytics or AI service by this integration. No advertising or analytics scripts are included on this website.

The use of information received from Google APIs is limited to these user-facing features and is subject to the Google API Services User Data Policy, including its Limited Use requirements.

Retention, revocation and deletion

The owner controls the files stored in Google Drive. Deleting a file through the mounted folder sends it to Drive's trash with the current rclone configuration. Google manages its trash retention and recovery.

The owner can revoke this application's Google access through Google Account connections, unmount the filesystem, and remove the local application configuration and logs. Revoking access or removing local configuration does not by itself delete the owner's remote Drive files.

Security

Google authorization takes place on Google's sign-in pages. The desktop integration uses HTTPS for Google API traffic. Local credentials and logs should remain accessible only to the computer's owner and authorized system administrators. This website does not ask for a Google password or collect OAuth tokens.

Website hosting

This static website is hosted on GitHub Pages. GitHub may process ordinary website request information under its privacy statement. No Drive contents, OAuth credentials or private file listings are included in the public site.

Contact and changes

For questions, contact the maintainer through the public profile at github.com/narutouzcoding-sketch. Material changes to the way this integration uses Google data will be disclosed before new consent is requested when required.
